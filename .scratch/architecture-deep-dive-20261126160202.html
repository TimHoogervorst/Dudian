How Practice generates a story

flowchart TD
A[Confirmed preview] --> B[Select vocabulary and review targets]
B --> C[Write title, teaser and every chapter]
C --> D[Validate whole draft]
D -->|Chapter error| E[Send full draft and request replacement chapter]
E --> D
D -->|Story error| F[Request complete story again]
F --> D
D -->|Retries exhausted| G[Record failure]
D -->|Accepted| H[Generate chapter questions]
H --> I[Save to Library]

Follow one request

practice-preview.ts · story-plan.ts · vocabulary-plan.ts assemble the confirmed plan. generation-job.ts starts the job. word-review.ts adds required review words. reading-format.ts · story-generation.ts build the prompt and validate the result. provider.ts sends each request independently. quiz-generation.ts builds checks against the accepted text. store.ts saves the completed reading.

Where work repeats

A single unlisted token triggers a replacement chapter. That replacement can invalidate coverage established in earlier drafts. The job stores the latest status and error while draft text lives in the running generation call.
